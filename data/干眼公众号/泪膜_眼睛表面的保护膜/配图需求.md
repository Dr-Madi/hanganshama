# 配图需求

正文图放 `imgs/`，文件名与正文引用一致。

## 风格（函干啥嘛，沿用医荟她模板）

- 文章排版：image-gallery 案例 `layout-yihui-lavender`。在 image-gallery 项目的 `wechat/styles.json` 按 ID 读取完整模板与组件 HTML，用 render_bailongmen.py 渲染，品牌文字为函哥；不退化成只套 CSS。
- 正文配图（概念插图、流程图、数据图）：image-gallery 案例 `canghe-article-scientific`（科学图解）。按 ID 读取该案例的 `instructions` 和 `prompt.text`，参考样图 `assets/style-previews/canghe-article-scientific.webp`。白底、精细线条、分区标注和分色结构，整体沿用该案例，只换本篇已核实的内容，不与其他案例拼接。
- 数据图和流程图：图中文字和数字必须与下方清单逐字一致，不增不减、不自行改写；生成后逐项核对，任何一个数字或标签不对就重做；比例条、柱子等图形长短要与数值相符。
- 封面：image-gallery 案例 `canghe-cover-nature`（自然疗愈封面），参考样图 `assets/style-previews/canghe-cover-nature.webp`（按 封面轮换.md 选定）。整体沿用该案例的构图、配色、材质和文字层级，只换成本篇主题；样图里的英文或示例文字只学风格不照抄，封面文字只用中文建议标题和副标题；约 2.35:1 横幅，重新为中文标题留出安全区域，不拿正文图充当封面。
- 通用：图中文字用中文，清晰无错字；不画真实医生或患者头像、官方 Logo、二维码、商品包装或品牌；不画仿真病变、惊悚画面或夸大疗效；机制图不把相关画成因果。

## 正文配图

1. `imgs/01-tear-film-layers.png`（位于「02 三层结构：油、水、黏蛋白各管一摊」开头；类型：概念插图，概念示意）：用简洁线条画一个眼球表面的局部放大剖面（左侧小图为正面简笔眼睛，用放大镜圆圈引出右侧剖面），剖面从外到内依次是：最上方空气、脂质层（细薄浅黄色）、水液层（较厚浅蓝色）、黏蛋白层（贴着细胞的浅紫色）、最下方眼表上皮细胞（一排简笔细胞）。三层之间用渐变柔和过渡，不画成截然分开的硬边，体现“彼此交融”。每层右侧一个标注框，左侧用细引线标出来源。不画血管、病变或仿真眼球特写；各层厚度只是示意，不标数字。图中文字逐项如下：
   - 图中标题：泪膜的三个部分
   - 脂质层标注：脂质层（油）｜降低表面张力，帮助减少蒸发
   - 脂质层来源：来自睑板腺
   - 水液层标注：水液层（水）｜润滑、滋养、抗菌
   - 水液层来源：主要来自泪腺，少部分来自结膜
   - 黏蛋白层标注：黏蛋白层｜让泪液铺得开、挂得住
   - 黏蛋白层来源：来自眼表上皮细胞和结膜杯状细胞
   - 最上方标签：空气
   - 最下方标签：眼表上皮细胞
   - 底部小字：概念示意，各层厚度未按比例。三层是简化说法，实际上水和黏蛋白相互交融。数据来源：参考文献[1][3]

2. `imgs/02-blink-cycle.png`（位于「03 眨一下眼，泪膜就重铺一次」开头；类型：流程图）：一个顺时针的四步循环图（四个圆角框，用弧形箭头首尾相连成环），表示每次眨眼后泪膜的日常循环，这是正常生理过程，不是病情进展。每个框配一个简笔小图示（闭眼的眼皮、均匀的一层泪液、变薄的泪液、出现小干斑的泪液）。环的中央放一个小号补充框。图中文字逐项如下，不加其他数字：
   - 图中标题：眨一下眼，泪膜就重铺一次
   - 第 1 步框：眨眼：上眼皮把泪液拉过角膜表面
   - 第 2 步框：铺开：形成一层新的泪膜
   - 第 3 步框：变薄：两次眨眼之间，变薄大部分来自蒸发
   - 第 4 步框：如果一直不眨眼：通常不到半分钟就会破裂
   - 从第 4 步回到第 1 步的箭头旁标签：再眨一次眼，重新铺开
   - 中央补充框：干眼时，泪膜破裂通常比正常快一倍
   - 底部小字：箭头表示眨眼间隔里的正常循环，不表示病情进展。数据来源：参考文献[1]

3. `imgs/03-layer-to-type.png`（位于「05 哪一层出问题，干眼的类型就不一样」开头；类型：流程图）：左右对应图。左侧竖排四个来源框，右侧竖排四个干眼类型框，用横向细箭头一一对应（同一行同一颜色：脂质相关浅黄、水液相关浅蓝、黏蛋白相关浅紫、泪液动力学相关浅绿）；底部一个通栏框表示混合型，用浅灰色，上方四条细线汇入。箭头只表示“哪一部分出问题对应哪种类型”，不表示病情进展或先后顺序。图中文字逐项如下，不加任何数字：
   - 图中标题：哪部分出问题，对应哪类干眼
   - 第 1 行左框：脂质层的质或量异常 → 右框：脂质异常型（如睑板腺功能障碍、睑缘炎）
   - 第 2 行左框：水液性泪液生成不足或质的异常 → 右框：水液缺乏型（如干燥综合征）
   - 第 3 行左框：眼表上皮细胞（尤其杯状细胞）受损 → 右框：黏蛋白异常型
   - 第 4 行左框：眨眼异常、泪液排出异常、结膜松弛、眼睑异常 → 右框：泪液动力学异常型
   - 底部通栏框：混合型：以上两种或两种以上原因同时存在，临床最常见
   - 底部小字：分类依据中国干眼专家共识（2020 年）。具体类型需眼科检查判断。数据来源：参考文献[3]
