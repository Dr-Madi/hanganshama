# 摆龙门封面轮换

封面风格每篇换一个，按下表顺序循环，沿用医荟她的封面案例（image-gallery `wechat/styles.json` 里 kind 为 cover 的案例）。

## 规则

- 写稿任务数一数选题清单「已完成」里已有的文章数 `k`（不算标「跳过」的），这篇用下表第 `k mod 表长` 行（从 0 数）。第一篇用第 0 行。
- 选中的案例写进这篇的 `配图需求.md`「封面」那条；配图任务照那条生成。一篇文章定下来的封面风格以后不再改。
- 想换风格或调整顺序，直接改下表。不要放进技术感强、深色或游戏风的案例。
