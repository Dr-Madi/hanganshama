### 患者常见问题（问答稿）

- [ ] 人工泪液能天天点吗，会不会越点越依赖（重点：人工泪液是什么、含不含防腐剂的区别、单支装的意义、一天点几次、开封后能用多久、什么时候该复诊）
- [ ] 热敷眼睛对干眼有没有用，怎么敷才对（重点：热敷针对的是睑板腺、温度和时长的证据、怎么避免烫伤、哪些情况不适合热敷）
- [ ] 天天盯手机电脑，眼睛干得受不了怎么办（重点：看屏幕时眨眼变少变浅、休息间隔的证据、屏幕位置、环境湿度、什么时候需要就医）
- [ ] 干眼能治好吗，是不是要点一辈子眼药水（重点：干眼多为慢性、需要长期管理、分型不同治法不同、阶梯治疗思路、坚持与复诊）
- [ ] 戴隐形眼镜总觉得眼干，怎么办（重点：隐形眼镜和干眼的关系、佩戴时长与护理、什么时候该停戴、日抛等类型选择只讲类型不讲品牌）
- [ ] 做完近视手术眼睛干，多久能好（重点：屈光手术后干眼的原因、通常的恢复时间以研究为准、术前评估的重要性、术后怎么护理和复查）
- [ ] 绝经后眼睛特别干，和激素有关吗（重点：女性和年龄是干眼危险因素、性激素与眼表的研究证据、激素治疗对干眼的证据有限且结论不一致时如实说明、该看哪个科）
- [ ] 干眼要不要吃鱼油（重点：鱼油补充的随机对照研究结果、为什么早期研究和大型试验结论不同、普通人怎么看待营养补充）
- [ ] 眼睛又干又爱流泪，这到底是干还是不干（重点：反射性流泪的机制、泪液质量和数量的区别、其他会流泪的情况如泪道问题）
- [ ] 空调房、暖气房、坐飞机眼睛干，有什么办法（重点：环境湿度和气流的影响、加湿和避开出风口、长途飞行时怎么做）
- [ ] 眼干嘴也干，要不要查干燥综合征（重点：干燥综合征是什么、哪些信号要警惕、该挂哪个科、做哪些检查、眼科和风湿免疫科如何配合）
- [ ] 化眼妆、贴假睫毛、做睫毛嫁接，会加重眼干吗（重点：睑缘和睑板腺开口、眼线位置、卸妆清洁、睫毛美容胶水的刺激，只讲做法不推荐产品）
- [ ] 孩子也会得干眼吗（重点：儿童青少年干眼的常见原因、屏幕使用、过敏、什么时候带孩子看眼科）
- [ ] 干眼会不会把眼睛弄瞎，什么情况要马上去医院（重点：多数干眼不会致盲、严重干眼可损伤角膜、需要马上就医的危险信号）

### 科普

- [ ] 泪膜是什么：眼睛表面那层看不见的“保护膜”（重点：脂质层、水液层、黏蛋白层各自的作用，泪膜不稳定为什么会眼干、视物模糊）
- [ ] 干眼分两类：泪水不够，和泪水蒸发太快（重点：水液缺乏型、蒸发过强型、混合型；睑板腺功能障碍在蒸发过强型里的地位；为什么分型决定治法）
- [ ] 睑板腺功能障碍：藏在眼皮里的“油管”堵了（重点：睑板腺在哪、做什么、堵塞的原因和表现、眼睑清洁与热敷、医院的操作治疗有哪些）
- [ ] 去医院查干眼，会做哪些检查（重点：泪膜破裂时间、泪液分泌试验、眼表染色、泪河高度、睑板腺成像，各查什么、要不要做准备）
- [ ] 人工泪液怎么选：看成分，不看广告（重点：常见成分类别、有无防腐剂、黏稠度与视物模糊、单剂量包装，只讲类型不讲品牌）
- [ ] 这些药可能让眼睛变干（重点：按药物类别和通用名介绍，如部分抗组胺药、抗抑郁药、异维A酸、利尿剂等；不要自行停药，和开药医生商量）
- [ ] 干眼怎么治：从调整生活到医院治疗的阶梯（重点：国际报告和国内共识的分级管理思路，每一级做什么，抗炎和免疫调节药物只写通用名）
- [ ] 睑缘炎和睫毛里的螨虫，与干眼有什么关系（重点：睑缘炎的表现、蠕形螨的研究证据、眼睑清洁怎么做、哪些说法夸大了）
- [ ] 睡觉时眼睛闭不严，会让眼睛变干（重点：眼睑闭合不全的原因、晨起眼干眼痛、需要就医评估的情况）
- [ ] 强脉冲光、热脉动这些干眼治疗，适合谁（重点：针对睑板腺功能障碍的操作治疗、原理、现有证据、适合与不适合的人；不推荐机构，不写价格）
