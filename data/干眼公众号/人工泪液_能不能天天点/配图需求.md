# 配图需求

正文图放 `imgs/`，文件名与正文引用一致。

## 风格（函干啥嘛，沿用医荟她模板）

- 文章排版：image-gallery 案例 `layout-yihui-interview`。在 image-gallery 项目的 `wechat/styles.json` 按 ID 读取完整模板与组件 HTML，用 render_bailongmen.py 渲染，品牌文字为函哥；不退化成只套 CSS。
- 正文配图（概念插图、流程图、数据图）：image-gallery 案例 `canghe-article-scientific`（科学图解）。按 ID 读取该案例的 `instructions` 和 `prompt.text`，参考样图 `assets/style-previews/canghe-article-scientific.webp`。白底、精细线条、分区标注和分色结构，整体沿用该案例，只换本篇已核实的内容，不与其他案例拼接。
- 数据图和流程图：图中文字和数字必须与下方清单逐字一致，不增不减、不自行改写；生成后逐项核对，任何一个数字或标签不对就重做；比例条、柱子等图形长短要与数值相符。
- 封面：image-gallery 案例 `cover-minimal`（极简科学 · 医学封面），参考样图 `assets/style-previews/generated/cover-minimal.webp`（按 封面轮换.md 选定）。整体沿用该案例的构图、配色、材质和文字层级，只换成本篇主题；样图里的英文或示例文字只学风格不照抄，封面文字只用中文建议标题和副标题；约 2.35:1 横幅，重新为中文标题留出安全区域，不拿正文图充当封面。
- 通用：图中文字用中文，清晰无错字；不画真实医生或患者头像、官方 Logo、二维码、商品包装或品牌；不画仿真病变、惊悚画面或夸大疗效；机制图不把相关画成因果。
